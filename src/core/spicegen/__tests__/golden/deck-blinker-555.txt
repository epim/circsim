vpsu_bench vpsu_bench_int 0 DC 5
rpsu_bench vpsu_bench_int vcc 0.1

* ── model definitions (inlined from the bundled library) ──
.subckt NE555 gnd trig out reset ctrl thres disch vcc
*
* ---- internal 5k / 5k / 5k resistor divider ----
* VCC --[5k]-- ctrl(=2/3 Vcc) --[5k]-- ntrig(=1/3 Vcc) --[5k]-- GND
* The CTRL pin is brought out at the 2/3 node (so an external cap/voltage on
* CTRL shifts the upper threshold, per the datasheet).
rdiv_a vcc ctrl 5k
rdiv_b ctrl n13 5k
rdiv_c n13 gnd 5k
*
* ---- supply current ----
* The datasheet supply current (about 3 mA at 5 V, about 10 mA at 15 V, output
* low, no load) is nearly resistive. This shunt, together with the 15k divider
* above, draws about 3.1 mA at 5 V and 9.3 mA at 15 V.
rq vcc gnd 1.8k
*
* Start-up ramps used below, written out in each expression on purpose (an
* intermediate node would start at 0 V and hide the ramp from the first Newton
* pass):
*   sf = (time < 1e-6 ? 1 - time/1e-6 : 0) is 1 at time 0 and 0 from 1 us on;
*   mr = (time < 1e-6 ? time/1e-6 : 1)     is 0 at time 0 and 1 from 1 us on.
*
* ---- upper (threshold) comparator ----
* output -> 1 when THRES > CTRL (2/3 Vcc). Drives the latch RESET input.
* Smooth step 2 mV wide (1 V wide at time 0).
bcomphi chi gnd v = 0.5*(1 + tanh(v(thres,ctrl)/(0.002 + 1.0*(time < 1e-6 ? 1 - time/1e-6 : 0))))
*
* ---- lower (trigger) comparator ----
* output -> 1 when TRIG < 1/3 Vcc (node n13). Drives the latch SET input.
bcomplo clo gnd v = 0.5*(1 + tanh(v(n13,trig)/(0.002 + 1.0*(time < 1e-6 ? 1 - time/1e-6 : 0))))
*
* ---- active-low RESET pin gate (datasheet threshold about 1 V) ----
* rok -> 1 when the pin is high (latch allowed to run), -> 0 when pulled low.
brok rok gnd v = 0.5*(1 + tanh((v(reset,gnd) - 1)/0.05))
*
* ---- RS latch with active-low RESET pin override ----
* State node 'q' is algebraic: the voltage source below forces
*   q = run * ( clo + (1-clo)*mr*hold(q) ),   run = (1-chi)*rok,
*   hold(q) = 1 when q > 0.5, else 0.
* run is 0 whenever the upper comparator or the RESET pin resets the latch
* (RESET is dominant, per the datasheet) and clo = 1 sets it. The self-reference
* through hold(q) is the latch memory, with two branches:
*   set branch    q = run      (hold = 1), valid while run > 0.5
*   reset branch  q = run*clo  (hold = 0), valid while run*clo < 0.5
* so the latch resets when the upper comparator passes its midpoint (THRES =
* CTRL) or RESET falls through 1 V, and sets when the lower comparator passes
* its midpoint (TRIG = Vcc/3). The memory term is off at time 0 (mr = 0), so the
* operating point is the smooth function q = run*clo: output low and discharge
* on whenever neither comparator is active, with no memory to choose between two
* states. There is deliberately no capacitor or lag on q (see "Solver step"
* above): the real part's propagation delay (about 100 ns) is far below the
* step circsim normally takes.
bq q gnd v = v(rok,gnd)*(1 - v(chi,gnd))*( v(clo,gnd) + (1 - v(clo,gnd))*(time < 1e-6 ? time/1e-6 : 1)*(v(q,gnd) > 0.5 ? 1 : 0) )
* Read the latch state for the output. From 1 us on this is the same hard
* decision as the memory, so the output changes only when q jumps between
* branches. A readout that moved along a branch (q runs from 1 down to 0.5 on
* the set branch as THRES approaches CTRL) would let the discharge switch and
* THRES settle into an analog equilibrium at the threshold. At time 0 it is a
* smooth step of slope 8 per volt.
bqd qd gnd v = (time < 1e-6 ? 1 - time/1e-6 : 0)*0.5*(1 + tanh(8*(v(q,gnd) - 0.5))) + (time < 1e-6 ? time/1e-6 : 1)*(v(q,gnd) > 0.5 ? 1 : 0)
*
* ---- output buffer (pin 3) ----
* OUT is HIGH (Vcc - 0.5) when the latch is SET, LOW (0.1 V) when reset,
* through a small output resistance; RESET low forces the output to 0 V. The
* buffer is referenced to the gnd pin, so current the load pushes into OUT
* leaves through gnd on its own. A 0 V sense source in series with the output
* resistance measures the output current, and a controlled source moves the
* SOURCED current from vcc to gnd so the supply pin carries the load (faded
* out below about 2 V so a floating rail carries nothing).
bout obuf gnd v = v(rok,gnd)*( 0.1 + (v(vcc,gnd) - 0.6)*v(qd,gnd) )
rout obuf osns 10
vsns osns out 0
bsrc vcc gnd i = 0.5*(1 + tanh((v(vcc,gnd) - 1)/0.25))*0.5*( i(vsns) + sqrt(i(vsns)*i(vsns) + 1e-12) )
*
* ---- discharge transistor (pin 7, open collector to GND) ----
* The discharge transistor is ON (DISCH pulled to GND through 15 ohm) when the
* output is LOW (latch reset) and OFF (1 Gohm) when the output is HIGH. RESET
* low forces it ON. Modeled as a voltage-controlled conductance from DISCH to
* GND; the current it sinks leaves through the gnd pin. The state readout inside
* it is the same as qd from 1 us on, and softer than qd at time 0 (3 per volt),
* because the loop through THRES is what the operating point has to solve.
bdisch disch gnd i = v(disch,gnd)*( (1 - ((time < 1e-6 ? 1 - time/1e-6 : 0)*0.5*(1 + tanh(3*(v(q,gnd) - 0.5))) + (time < 1e-6 ? time/1e-6 : 1)*(v(q,gnd) > 0.5 ? 1 : 0))*v(rok,gnd))/15 + (((time < 1e-6 ? 1 - time/1e-6 : 0)*0.5*(1 + tanh(3*(v(q,gnd) - 0.5))) + (time < 1e-6 ? time/1e-6 : 1)*(v(q,gnd) > 0.5 ? 1 : 0))*v(rok,gnd))/1e9 )
.ends NE555

.save i(vsense_d1)
.end
