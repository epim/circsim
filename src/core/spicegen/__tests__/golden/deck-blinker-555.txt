* circsim deck — blinker-555
* U1: tier 1 (schematic Sim.*) | R1: tier 2 (primitive) | R2: tier 2 (primitive) | C1: tier 2 (primitive) | C2: tier 2 (primitive) | R3: tier 2 (primitive) | D1: tier 3 (bundled library)
vpsu_bench vpsu_bench_int 0 DC 5
rpsu_bench vpsu_bench_int vcc 0.1
x_u1 0 thres out vcc ctrl thres disch vcc NE555
r_r1 vcc disch 10000
r_r2 disch thres 47000
c_c1 thres 0 1e-5
c_c2 ctrl 0 1e-7
r_r3 out led_a 330
vsense_d1 led_a led_a__ledsense_d1 DC 0
d_d1 led_a__ledsense_d1 0 LED_RED
* ── model definitions (inlined from the bundled library) ──
.subckt NE555 gnd trig out reset ctrl thres disch vcc
*
* ---- internal 5k / 5k / 5k resistor divider ----
* VCC --[5k]-- ctrl(=2/3 Vcc) --[5k]-- ntrig(=1/3 Vcc) --[5k]-- GND
* The CTRL pin is brought out at the 2/3 node (so an external cap/voltage on
* CTRL shifts the upper threshold, per the datasheet).
rdiv_a vcc ctrl 5k
rdiv_b ctrl n13 5k
rdiv_c n13 gnd 5k
*
* ---- upper (threshold) comparator ----
* output high when THRES > CTRL (2/3 Vcc). Drives the latch RESET input.
bcomphi chi gnd v = ( v(thres) > v(ctrl) ) ? 1 : 0
*
* ---- lower (trigger) comparator ----
* output high when TRIG < 1/3 Vcc (node n13). Drives the latch SET input.
bcomplo clo gnd v = ( v(trig) < v(n13) ) ? 1 : 0
*
* ---- RS latch with active-low RESET pin override ----
* State node 'q' is the latch output and holds in [0,1]. It is realized as a
* capacitor integrated by a push/pull current:
*   - SET   (clo high, lower comparator): push q up toward 1
*   - RESET (chi high, upper comparator) OR external RESET pin low: push q down
*   - otherwise HOLD (no current -> the cap retains its value = memory)
* The push currents only act while q is moving toward the target (gated by the
* target so q parks cleanly at 0 or 1), and a strong clamp keeps q in [0,1].
* RESET is made dominant over SET (datasheet: reset/threshold wins).
.param islew = 100m
blatch 0 q i = ( (v(reset) < 1) || (v(chi) > 0.5) ) ? ( (v(q) > 0.0) ? (-islew) : 0 ) : ( (v(clo) > 0.5) ? ( (v(q) < 1.0) ? (islew) : 0 ) : 0 )
cq q 0 1n ic=0
* hard clamp: strong restoring current if q leaves [0,1].
bclamp 0 q i = (v(q) > 1) ? (-(v(q)-1)*10) : ( (v(q) < 0) ? (-v(q)*10) : 0 )
* read the latch state through a clean 0/1 decision (mid-point threshold).
bq qd gnd v = ( v(q) > 0.5 ) ? 1 : 0
*
* ---- output buffer (pin 3) ----
* OUT is HIGH (≈Vcc) when the latch is SET, LOW (≈0) when reset. Push-pull
* through a small output resistance; clamp to the rails. RESET low forces low.
bout obuf gnd v = ( v(reset) < 1 ) ? 0 : ( ( v(qd) > 0.5 ) ? (v(vcc)-0.5) : 0.1 )
rout obuf out 10
*
* ---- discharge transistor (pin 7, open collector to GND) ----
* The discharge transistor is ON (DISCH pulled to GND) when the output is LOW
* (latch reset), and OFF (high-Z) when the output is HIGH. Modeled as a
* voltage-controlled resistance from DISCH to GND.
bdisch disch gnd i = ( (v(qd) < 0.5) || (v(reset) < 1) ) ? ( (v(disch)-v(gnd))/15 ) : ( (v(disch)-v(gnd))/1e9 )
.ends NE555
.model LED_RED D(is=1e-19 rs=2.0 n=1.7 cjo=30p vj=0.75 m=0.333 bv=5 ibv=100u eg=1.9 xti=3)
.save all
.save i(vsense_d1)
.end
